# CitaRural - Grupo 04

Módulo de software en Python para digitalizar el registro de pacientes, citas médicas y reportes de atención en establecimientos de salud rurales del Perú.

## Problema

En el Perú, la falta de sistemas informáticos en centros de salud rurales genera pérdida de datos clínicos, duplicación de registros y demoras en la atención médica. El Centro de Salud Rural “Santa Rosa”, en Cajamarca, evidencia esta problemática al gestionar pacientes y citas mediante registros físicos, requiriendo una solución de software que permita digitalizar sus procesos y mejorar la atención.

## Objetivo

Diseñar e implementar un módulo funcional que permita registrar pacientes, gestionar citas médicas y generar reportes de atención, aplicando programación orientada a objetos, código limpio y tratamiento seguro de datos personales (Ley N.° 29733).
